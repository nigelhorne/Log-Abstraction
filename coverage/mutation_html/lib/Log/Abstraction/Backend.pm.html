   23: =head1 NAME
   24: 
   25: Log::Abstraction::Backend - base class of the Log::Abstraction backends
   26: 
   27: =head1 VERSION
   28: 
   29: 0.39

   31: =head1 DESCRIPTION
   32: 
   33: For use by L<Log::Abstraction> only.  C<Log::Abstraction-E<gt>new()> builds
   34: one object of a C<Log::Abstraction::Backend::*> class for each place a
   35: message goes to (a file, an array, syslog ...), and each message is passed to
   36: every one of them.  The configuration given to C<new()> is not changed.
   37: 
   38: The backends are:
   39: 
   40:   Log::Abstraction::Backend::Array        array, or logger => \@array
   41:   Log::Abstraction::Backend::Code         logger => \&code
   42:   Log::Abstraction::Backend::Fd           fd
   43:   Log::Abstraction::Backend::File         file, or logger => $path
   44:   Log::Abstraction::Backend::Journald     journald
   45:   Log::Abstraction::Backend::LogAny       log_any, or a Log::Any logger
   46:   Log::Abstraction::Backend::LogDispatch  log_dispatch, or a Log::Dispatch object
   47:   Log::Abstraction::Backend::Object       any other object as the logger
   48:   Log::Abstraction::Backend::Sendmail     sendmail
   49:   Log::Abstraction::Backend::Syslog       syslog
   50:

  103: =head2 emit
  104: 
  105:   $backend->emit($logger, $event);
  106: 
  107: Sends a message, which has passed the logger's level, to the backend.
  108: C<$logger> is the C<Log::Abstraction> object.  C<$event> is a hash
  109: reference built by C<Log::Abstraction> for each message:
  110: 
  111:   level        the level name, e.g. 'warn'
  112:   priority     its syslog number (0-7)
  113:   message      the message, its parts joined and redacted
  114:   parts        the message's parts (an array reference)
  115:   fields       the structured fields (a hash reference), or undef
  116:   fields_text  the fields as key=value text, or undef
  117:   text         the message with fields_text appended
  118:   entry        the history entry (a list, as an array reference)
  119:   class, file, line, ctx   for CODE references
  120:   render       format a line: $event->{render}->($format), undef for
  121:                the logger's format
  122:   write        write a line to a path (which it checks) or a handle:
  123:                $event->{write}->($target, $line)
  124:   send_email, hold_email   send or keep for later an email:
  125:                $event->{send_email}->(\%sendmail, $body)
  126: 
  127: The closures are how a backend uses Log::Abstraction's private methods.
  128: Subclasses must override this.
