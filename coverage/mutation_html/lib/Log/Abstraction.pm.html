 1922: =head1 LIMITATIONS
 1923: 
 1924: =over 4
 1925: 
 1926: =item B<Syslog hash mutation>
 1927: 
 1928: The C<syslog> sub-hash passed to C<new()> is mutated in-place on the first
 1929: log call: C<facility> and C<level> are temporarily removed before
 1930: C<setlogsock()> is called, then restored; C<server> is permanently renamed
 1931: to C<host>.  Sharing a syslog hashref between two C<Log::Abstraction>
 1932: instances is not supported and produces undefined behaviour on the second
 1933: instance.
 1934: 
 1935: =item B<No structured log fields>
 1936: 
 1937: All backends except the CODE-ref backend reduce the message to a flat string.
 1938: To log structured key/value pairs, use a CODE-ref backend that formats the
 1939: data itself.
 1940: 
 1941: =item B<Single-threaded email throttle>
 1942: 
 1943: The C<min_interval> throttle for the C<sendmail> backend and the
 1944: C<_syslog_opened> first-open flag are stored on the object without mutex
 1945: protection.  Under Perl ithreads or other concurrency models, objects shared
 1946: between threads are not safe.
 1947: 
 1948: =item B<OpenTelemetry not yet supported>
 1949: 
 1950: The OTel Logs SDK for Perl is incomplete; see the TODO block at the top of
 1951: F<lib/Log/Abstraction.pm> for a full status report and the list of blockers.
 1952: Monitor L<https://metacpan.org/pod/OpenTelemetry::SDK> for progress.
 1953: 
 1954: =item B<Log::Log4perl is a de-facto required dependency>
 1955: 
 1956: When no C<logger>, C<file>, or C<array> backend is configured, C<new()>
 1957: loads L<Log::Log4perl> and uses it as the default backend.  Although listed
