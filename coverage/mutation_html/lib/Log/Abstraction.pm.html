   40: 
   41: The C<Log::Abstraction> class provides a flexible logging layer on top of different types of loggers,
   42: including code references, arrays, file paths, and objects.
   43: It also supports logging to syslog if configured.

   78: This allows the parameters to be set at run time.
   79:

   82: For example:
   83:

   85:

   87:

   89: 
   90: The minimum level at which to log something,
   91: the default is "warning".
   92: 
   93: =item * C<logger>
   94: 
   95: A logger can be one or more of:
   96: 
   97: =over
   98: 
   99: =item * a code reference
  100: 
  101: The code will be called with a hashref containing:
  102: 
  103: =over
  104: 
  105: =item * class
  106: 
  107: =item * file
  108:

  115: =item * ctx - passed to C<new()>, an argument that can help to give context to the caller
  116: 
  117: =back
  118: 
  119: =item * an object
  120: 
  121: =item * a hash of options
  122: 
  123: =item * sendmail - send higher priority messages to an email address
  124: 
  125: To send an e-mail,
  126: you need L<require Email::Simple>, L<require Email::Sender::Simple> and L<Email::Sender::Transport::SMTP>.
  127: 
  128: The C<sendmail> hash also accepts a C<min_interval> key (seconds).
  129: When set, at most one email is sent per C<min_interval> seconds; any

  858: =head2 CSV file logging for BI import
  859: 
  860: The code-reference backend gives you full control over the output format.
  861: The example below writes every message at C<trace> level and above as a
  862: CSV row to a file,
  863: producing output that can be loaded directly into a spreadsheet or BI tool
  864: (Tableau, Power BI, Metabase, etc.).
  865: 
  866: Each row contains: C<timestamp>, C<level>, C<class>, C<file>, C<line>, C<message>.
  867: 
  868:   use Log::Abstraction;
  869: 
  870:   my $csv_file = 'app_events.csv';
  871: 
  872:   # Write the header row once (skip if the file already exists and has data).
  873:   unless (-s $csv_file) {
  874:       open my $fh, '>', $csv_file or die "Cannot open $csv_file: $!";
  875:       print $fh qq{timestamp,level,class,file,line,message\n};
  876:       close $fh;
  877:   }
  878: 
  879:   # Helper: quote a single CSV field (escapes embedded double-quotes).
  880:   my $csv_field = sub {
  881:       my $v = defined $_[0] ? $_[0] : '';
  882:       $v =~ s/"/""/g;
  883:       return qq{"$v"};
  884:   };
  885: 
  886:   my $logger = Log::Abstraction->new(
  887:       level  => 'trace',        # capture everything from trace upwards
  888:       logger => sub {
  889:           my $args = $_[0];
  890: 
  891:           my $timestamp = POSIX::strftime('%Y-%m-%dT%H:%M:%SZ', gmtime);
  892:           my $message  = join(' ', @{ $args->{message} // [] });
  893: 
  894:           open my $fh, '>>', $csv_file or return;
  895:           print $fh join(',',
  896:               $csv_field->($timestamp),
  897:               $csv_field->($args->{level}),
  898:               $csv_field->($args->{class}),
  899:               $csv_field->($args->{file}),
  900:               $csv_field->($args->{line}),
  901:               $csv_field->($message),
  902:           ), "\n";
  903:           close $fh;
  904:       },
  905:   );
  906: 
  907:   $logger->trace('application started');
  908:   $logger->info('user logged in', { user => 'alice' });
  909:   $logger->warn({ warning => 'disk usage above 80%' });
  910:

  912: 
  913:   timestamp,level,class,file,line,message
  914:   "2026-05-27T14:00:00Z","trace","Log::Abstraction","app.pl","42","application started"
  915:   "2026-05-27T14:00:01Z","info","Log::Abstraction","app.pl","43","user logged in"
  916:   "2026-05-27T14:00:02Z","warn","Log::Abstraction","Log/Abstraction.pm","820","disk usage above 80%"

  919: module).  For C<trace>, C<debug>, C<info>, and C<notice> calls, C<file> and C<line>
  920: resolve to the caller's source location.  For C<warn> and C<error> calls the
  921: extra C<_high_priority> stack frame shifts the resolution one level inward, so
  922: C<file> and C<line> point into the module rather than the calling script.
  923:

  925: L<Text::CSV> for correct handling of embedded newlines and other edge cases.
  926:

  928: directly inside the code-ref callback â€” test C<$args-E<gt>{level}> and call
  929: your mailer for C<warn> / C<error> messages while still writing the CSV row
  930: for every message.

  932: Alternatively, use the C<sendmail> hash-ref backend on its own (without the
  933: code-ref) and add a C<level> key to restrict emails to warn-and-above:
  934: 
  935:   my $logger = Log::Abstraction->new(

  943:               level        => 'warn',   # only email at warn level and above
